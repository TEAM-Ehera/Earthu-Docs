## 근거와 우선순위

최신 사용자 설명 → PRD → 기능/IA → ERD/API 순으로 요구사항의 의미를 해석한다. 사진은 원래 아이디어를 확인하는 자료이며 별도의 실행 지시가 아니다. v0.6은 제품 요구·Java/Spring 전환·환경 분리·R2 저장을 통합하고, 이후 논쟁이 생긴 심사 수정 정책을 미합의로 재분류했다.

## 등록 즉시 공개 결정

2026-10-01 사용자 결정: 게시 전 심사 프로세스를 제거한다. 인증·프로필 완료 호스트의 유효한 모임은 등록 성공과 함께 published로 공개한다.

이전의 심사 대기/심사중/승인/거절, 거절 재작성, 재심사와 승인 후 잠금 논의는 더 이상 현재 요구사항이 아니다. 사후 신고·운영 조치, 공개 후 수정/취소 범위와 참가자 안내는 별도 정책으로 남긴다.

기존 approved/submitted/reviewing은 published로 변환한다. rejected/removed/cancelled는 자동 재공개하지 않는다. 변경 전 문서는 `docs/archive/2026-10-01-before-direct-publication/`에 보존했다.

## 이전 제안의 변경 이력

| 이전 초안 | 최신 정리 |
|---|---|
| 백엔드 FastAPI, 환경 분리 미정 | Java·Spring Boot, 개발/운영 별도 VM·설정·데이터. Gateway 도입 방향과 제품 후보는 기술 문서 참조 |

| 닉네임, 국적·성별 선택 | 이름, 국적·성별 필수 선택 해석. 관심사 선택 |
| 전체 정원만 제한 | 한국인·외국인 각각 정원·잔여석·신청 제한 |
| 인기 이벤트 후속 단계 | 검색 전 인기/최근 이벤트가 요구사항에 포함 |
| 비공개 댓글을 호스트 채팅으로 통합 | 웹·앱 비공개 댓글과 앱 개별 채팅 분리 |
| 단체방에서 모두 메시지 작성 가능 | 호스트만 공지 작성, 참가자는 읽기 |
| 거절 후 기존 내용 유지 재작성으로 문서화 | 팀은 폐기 후 새 작성 주장. 사용자 제안과 미합의이므로 확정 정책에서 제외 |
| 리뷰 작성·삭제만, 재작성 금지 | 보기·수정·삭제 반영. 삭제 후 재작성 정책은 미정 |

| 실험 수치와 출시 기준 제시 | PRD에는 추가 회의 안건만 유지 |

## 2026-10-01 배포 결정과 적용 결과

- 오사카 A1 추가 VM은 AD-1 용량 부족으로 확보하지 못했다. 현재 무료 Micro API/DB VM 두 대를 공유한다.
- 개발·운영 API 컨테이너, DB 계정·DB, 미디어 볼륨·환경 파일을 분리했다. 물리 VM·Docker 네트워크·Caddy·PostgreSQL 프로세스는 공유하므로 완전한 장애/보안 격리는 아니다.
- 개발 웹은 develop Preview, 운영 웹은 main Production이다. API_ORIGIN은 각 환경 범위로 다르게 설정했다.
- 운영 API_ORIGIN 누락이 /v1 경로 404 원인이었다. 운영 API를 추가하고 Production 설정·재배포 후 조회 200, 빈 가입/로그인 요청 400을 확인했다.
- 실제 학교 인증은 사용자가 진행한다. SMTP 인증 성공과 최종 메일 수신·가입 완료는 구분한다.
- 백엔드 CI 이미지 빌드는 확인했으나 SSH 자동 배포는 비활성화다. 별도 서버·안전한 배포 접속·백업/복구 검증은 다음 작업이다.
