# 얼쑤 프로젝트 백로그

기준일: **2026-10-07 · Asia/Seoul**

현재 작업 폴더의 제품 문서, 웹·API 커밋 이력, 미커밋 변경, 백업 복원 보고서를 바탕으로 정리했다. 이 문서를 만들면서 운영 서버나 GitHub의 현재 PR 상태를 새로 조회하지는 않았다. 완료 날짜는 기록에서 확인되는 날짜이며, 앞으로의 일정은 **제안**이다. 담당자와 마감일은 아직 확정하지 않았다.

개인별 기여 기록이 충분하지 않아 아래는 **현재 프로젝트에서 수행한 작업** 기준이다. 웹·API의 확인한 커밋 작성자는 TheSoftBelly이며, 팀 작업을 포함한 문서상의 성과 전체를 개인 단독 성과로 단정하지 않는다.

## 사용자 검증·개발 주소 후속 · 2026-10-09

- 사용자가 실제 학교 메일로 계정 검증(가입 → 메일 수신·코드 인증 → 프로필 → 로그인 → 비밀번호 재설정 → 전체 기기 로그아웃)을 이미 진행했다고 보고했다. BL-04의 실제 학교 메일 검증과 BL-03의 계정 사용자 흐름 검증은 이 보고를 최신 상태로 반영한다. 이 기록은 에이전트가 운영 데이터를 새로 검증한 결과가 아니다.
- 두 계정의 모임 생성·참여·취소, 정원·권한 검증(BL-05~06)은 별도 남은 작업이다.
- 개발 웹 주소도 earthuu 브랜드로 변경하는 후속 작업을 추가한다. 제안 고정 주소는 `https://earthuu-dev.vercel.app`이며 아직 전환 완료가 아니다. Vercel 개발 연결, 개발 `NEXT_PUBLIC_SITE_URL`, API `WEB_ORIGIN`, 카카오 JavaScript SDK 도메인, 공유 문서를 함께 갱신하고 로그인·지도·noindex를 확인한다.
- 10/9 확인 시 API VM의 SSH 접속은 시간 초과였다. 서버 허용 도메인 변경과 검증 전에는 기존 개발 주소를 유지한다.
- 인증 보호·계정 관리·V5는 10/8 개발/운영 배포 기록상 적용 완료다. 이전 표의 배포 대기 상태보다 최신 배포 기록을 우선한다. 배포에 포함된 로컬 변경의 Git 반영은 아직 필요하다.
