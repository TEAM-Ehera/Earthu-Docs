## 현재 구현과 확인 범위

등록 즉시 공개, 주최자 수정·취소·신청자 조회, 이미지 압축·한도, JWT 자동 갱신과 서버 지표 수집은 기존 문서에 구현·배포 완료로 기록되어 있습니다. Java 테스트 11개와 웹 lint·타입 검사·빌드 통과 기록이 있습니다. 이 문서 공유 작업에서 운영 서버나 코드를 다시 검증한 것은 아닙니다.

학교 메일 실제 수신·가입·프로필·작성·다른 계정 참여 흐름은 검증 대기입니다. 지표 수집과 외부 장애 알림은 별개이며 외부 알림은 미연동입니다. 과거 배포 문서의 당시 상태보다 2026-10-02 기록을 우선합니다.

제품 문서 14종, 문서 지도와 ERDCloud SQL을 가져왔습니다. 과거 아카이브와 개인 환경 파일은 포함하지 않았습니다. GitHub에서 탐색하도록 위키링크를 Markdown 링크로 변환했습니다. 서버 IP·관리자 계정 식별자를 제외한 공개 공유본입니다. Grafana 주소·개인 Viewer 계정은 운영 담당자가 별도 전달합니다.

## 최신 개발 상태 추가 — 2026-10-02

카카오 장소 검색·선택·지도 표시와 Redis를 개발·운영에 배포했고 운영 웹 지도 표시를 확인했습니다. API 장소 PR은 병합 완료, 웹 장소 PR은 검토 중입니다. 새 모임 저장·재조회와 실제 가입·참여 전체 흐름은 남아 있습니다. 개발 현황의 완료 항목과 남은 작업을 최신 기록에 맞췄습니다. Swagger·관리자 인수인계·웹 상세 화면 수정은 로컬 미커밋 작업으로 구분했으며 서버 접속 상세는 공개하지 않습니다.
