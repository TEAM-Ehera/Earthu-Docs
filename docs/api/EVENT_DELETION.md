# 주최한 모임 삭제

`DELETE /v1/events/{id}/host`

- 로그인 쿠키와 기존 요청 보호 헤더 `X-Eolssu-Request: 1`이 필요합니다. 요청 본문은 없습니다.
- 본인 주최 모임만 삭제할 수 있습니다. 시작 전·지난 모임·취소된 모임 모두 가능합니다.
- 성공은 `204`, 비로그인은 `401`, 다른 주최자의 모임은 `403`, 없거나 이미 삭제된 모임은 `404`입니다.
- 이벤트를 잠근 뒤 `status=deleted`로 저장합니다. 관련 참여·댓글·후기·신고 이력은 보존합니다.
- 삭제한 모임은 공개 목록, 내 주최·관심·참여 목록, 상세 및 주최자 조회에서 제외됩니다. 기존 published 전용 상호작용도 사용할 수 없습니다.
- 기존 `DELETE /v1/events/{id}`와 `{ "reason": "취소 사유" }`는 시작 전 모임 취소 기능으로 유지됩니다. 취소는 `cancelled`로 저장하여 상세와 참여 목록에 남습니다.

웹의 내 모임 → 주최한 목록, 모임 상세, 모임 관리 화면에서 삭제 버튼을 제공합니다. 확인 창에서 참여자 접근 차단과 되돌릴 수 없음을 안내하고, 삭제 중 중복 요청을 막습니다. 목록에서는 성공한 이벤트를 즉시 제거하고, 상세·관리에서는 주최한 목록으로 이동합니다.

검증: `EventDeletionHttpTests`에서 권한·상태·시작 시각·반복 삭제·삭제 후 조회를, `DeletedEventListTests`에서 내 목록 제외를 확인합니다.
